# Green Initiative - Demo Website

A fictional environmental NGO website created for portfolio and learning purposes.

## 📌 Disclaimer

**This is NOT a real organization.** This website is a demo project created to showcase web development and design skills. No donations are being collected, no real environmental work is being done, and all content is fictional.

The PayPal button uses a placeholder ID and does not process actual payments. The contact and partnership forms do not send real emails or store real data.

## 🎨 Design

- **Color Palette:** #172711 (deep forest), #1A936F (vibrant green), #EEFFED (soft mint)
- **Font:** Space Grotesk
- **Style:** Brutalist / expressive with bold typography and asymmetric layouts

## 🛠️ Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- Font Awesome Icons
- Google Fonts
